## 说话人映射（最高风险！）

### 反面案例：08-09 场我连续判错两次

**真实情况**：

| ASR 标签 | 我两次都判成 | 实际 |
|---|---|---|
| 🟢 郭磊 | 郭磊 ✅ | 郭磊 |
| 🟣 说话人2 | Harry ✅（用户首次确认） | Harry |
| 🔵 说话人3 | **夏老师** ❌ | **郭志梁**（主导商业规划） |
| 第四人 | 郭志梁（"发言被并入"）❌ | 夏老师（发言少，未识别） |

**为什么错**：

1. 第一次：郭磊在 `[01:28:08]` 直接称呼说话人3 为"夏老师"——我以为说话人3 = 夏老师
2. 第二次：基于这次错误，把郭志梁当成"发言被并入的隐形人"
3. **真相**：说话人3 是郭志梁（主导商业规划、做视频号、润商会合伙人、公司年营收一亿）；郭磊叫的"夏老师"是郭志梁的称呼（可能被叫夏老师/被 ASR 同音误听/旧称）
4. **夏老师是另一个人**，在场但发言不多

### 方法论：角色指纹 + 时间线核对 + 用户二次确认

#### Step 1：列每个 ASR 标签的「角色指纹」

| 指纹维度 | 提取什么 |
|---|---|
| 主导什么内容 | 技术？商业规划？主持？咨询？ |
| 自述身份 | "我公司""我们公司""我跟刘志伟""我搞了视频号" |
| 被他人称呼 | 谁叫你？叫你什么？ |
| 第一次出现时间 | `[HH:MM:SS]` 上车 / 插话 / 加入 |
| 语用风格 | 短接话 vs 长论证 vs 提问推动 |

#### Step 2：交叉校验（必须做）

| 校验项 | 怎么查 |
|---|---|
| **主导 vs 标签** | 用户说"主导 X 的是 Y" → Y 对应的 ASR 标签 = X 的主导者 |
| **时间线一致性** | 如果 X 在 `[00:20:07]` 才到场，则 `[00:20:07]` 之前被 ASR 标为 X 标签的回合**可能不是 X**（或是 X 早就在场但 ASR 误标） |
| **称呼 ≠ 身份** | A 被 B 叫"夏老师"≠ A 就是夏老师。称呼可能是绰号 / 旧称 / 同音误听 |
| **自述内容 vs 指纹** | 说话人3 自述"我跟刘志伟是润商会合伙人"→ 润商会合伙人身份锁定 |

#### Step 3：用户二次确认（绝不能省）

**哪怕第一步感觉很清楚，也要让用户确认**。本次示例对话：

> **AI**：转写里"说话人2（🟣，全场技术核心：讲服务器成本/token/K3/agent部署，有海外工作背景）"对应哪位参与人？
> **用户**：说话人2 = Harry
>
> （数小时后，用户主动补充）
>
> **用户**：主导做商业规划的是郭志梁，再次结合原文分析
> **AI**：重新分析后发现说话人3 是郭志梁，主导商业规划，做视频号…
> **用户**：做视频号、润商会的是郭志梁，主导商业规划的也是郭志梁，夏老师说话不多

**要点**：

1. 第一次确认时不要假设其他说话人的身份——只问最不确定的那个
2. 用户可能第一次答得不完全准确（信息有限/记不清），必须**保留后续追问 / 二次确认的余地**
3. 一旦发现新矛盾（如"主导商业规划的 X"对不上当前映射），立即回原文复核，而不是猜测

#### Step 4：识别身份存疑的发言（不要硬拆）

有些回合确实无法判断是谁说的（ASR 合并 + 无音频）：

- **不要硬拆** —— 保留原归属，在附录"说话人说明"里标注
- 不要为了"还原得漂亮"而臆造身份
- 把无法确定的回合明确划入"未识别"

### 改名映射时的"称呼与标签不一致"处理

修正映射后，原话里的称呼词（被叫的称呼）**必须保留**（金句原则：原话一字不改）。但头部必须显式说明：

```markdown
- 🟢 **郭磊** = …
- 🟣 **说话人2 → Harry** = …
- 🔵 **说话人3 → 郭志梁** = …[00:20:07] 到场加入；本场商业规划主导者…
- **夏老师** = 在场参与，发言不多，ASR 未单独识别。注意：原文中郭磊、Harry 多次以"夏老师"相称，该称呼多指向郭志梁（说话人3）；个别处（如 [02:07:38]、[02:35:00] 郭志梁自述团队"咨询由夏老师、郭老师提供"）指真正的夏老师作为咨询顾问之一。原话中"夏老师"称呼词一律保留不改，由本说明区分。
```

读者看 `**【郭志梁】** [01:28:08]` 但话里说"夏老师巨牛逼"——结合头部说明，立刻理解"夏老师"是郭磊对郭志梁的称呼。

## 时间线核对（必查）

| 时间线冲突类型 | 例子 | 处理 |
|---|---|---|
| X 在 [00:20:07] 才到场，但 [00:15:32] 有人叫 X 发言 | 误识别 → 撤销 | 恢复原 ASR 归属，标注"口误/存疑" |
| X 自述"我们公司一亿"但 Y 才是那个公司的人 | 矛盾 → 查上下文 | 看完整段判断 |
| 同一句话两人轮换太快，ASR 标错 | 错位 | 逐字比对原文转写 |

**任何说话人改动，都要重新跑时间线核对**。
