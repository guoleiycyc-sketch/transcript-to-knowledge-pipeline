# 子代理模式（批量清洗 + 单场委派）

用轻量模型子代理（低成本快速档位）承担清洗稿生产，主对话只做不可委派环节。两种模式互补：

| 模式 | 适用 | 省什么 |
|---|---|---|
| **批量清洗** | 几十场存量的一次性清理 | 省（总）人 |
| **单场委派** | 新场次的日常清洗 | 省主对话上下文 |

**启用条件**：项目根 `pipeline.config.json` 的 `delegation.enabled=true`。无 config 的项目默认主对话直洗（不启用）。

## 分工纪律：映射与提炼不委派

| 环节 | 执行者 | 说明 |
|---|---|---|
| 说话人映射 | **主对话** | 读原文（短场全读/长场读头尾+抽中段），产出映射结论+存疑词表——最高风险环节，不委派 |
| 01 清洗稿 | **子代理** | 自包含 prompt 五要素（见下），分节框架可主对话给定（短场）或让代理按话题自定（长场 8-10 节） |
| 格式自检+忠实度抽验 | 主对话 | 质检三件（见下） |
| 02-09 模块提炼 | **主对话** | 价值核心不委派；基于 01 与映射，无需重读原文 |
| 渲染+场后同步 | 主对话 | render_pack → 索引/README/atoms/视图（见 references/07） |

## 委派 prompt 五要素（缺一即漂移）

1. **映射结论**：标签→人名+置信度依据；身份未定者保留原标签+存疑说明
2. **本场词表命中**：确定条目（直接还原）与存疑条目（保留原词+标注）分开列
3. **清洗原则**：合并碎片/去口水/金句原话不改/回合格式 `**【人名】** [HH:MM:SS]`
4. **分节框架**：短场给固定节界，长场给话题锚让代理自定；会后混录段→移附录的指令
5. **输出纪律**：中间回复 ≤2 句；**每次写入 ≤120 行**；Write 头部+`<!-- APPEND_MARKER_N -->` 分块 Edit；写完自检（畸形回合=0/锚点=0）报回合分布

完整可复制模板见本文件附录。

## 主对话质检协议（三件）

```bash
# 1 格式权威统计（勿用 grep——macOS UTF-8 字符类有坑，用 python re）
python3 -c "import re,collections; c=collections.Counter(m.group(1) for m in re.finditer(r'\*\*【([^】]+)】\*\* \[', open('<01路径>').read())); print(dict(c))"

# 2 忠实度抽验（时间戳对齐法，期望平均 0.65-0.85=正常清洗区间；<0.5 需逐段人工复核）
#    按 01 回合时间戳取原文同时间戳块为锚 + 向后相邻 1-4 块拼接取最优比对
#    （勿用 ±60s 窗口拼接——对合并幅度大的回合系统性误报，见坑库 P38）

# 3 引文终校（02/08 引文 vs 01 归一化子串）
#    子代理版 01 若用自定义骨架，官方 verify_quotes 会跳过，用替代脚本：
#    strip 括注/标注 → norm 标点 → 逐条 in 判断（先 strip 再 norm，顺序反了括注会残留假阳性）
```

## 批量模式要点

**架构**：主对话指挥（派发清单、逐场质检、索引打 ✅、异常处理、全局层同步）+ 子代理执行 + 主对话质检。

- 分派粒度：按目录分批，每批一个子代理顺序处理或多个并行
- **派发前先查来源索引的 ✅ 标记与既有场次目录，防重复清洗**
- 每场质检：pipeline_check + verify_quotes + 抽查头部映射与存疑项登记 + 索引打 ✅

**已知运营事件与处理**：

| 事件 | 处理 |
|---|---|
| 模型内容审查拦截（涉敏感时政话题的场次） | 子代理无法处理 → 转主对话清洗，或用户裁决放弃留档 |
| 同源双稿（同一录音两份转写） | 择一清洗，另一份索引注「同源并档」 |
| 特长场（>4h） | 先探测空档判连续/拼接，拆窗口清洗、窗口独立编号 |
| 说话人存疑累积 | 汇总到「待用户复核清单」，收尾批量请用户裁决 |
| 同日多切片（一次活动被切成多条录音） | 并档为一场，索引注明 |

**批量收尾**（全部完成后）：

1. 存疑清单批量裁决 → 子代理并行订正场次产物 + 主对话订正全局层（词表/干系人/索引）
2. `extract_atoms.py <项目根>` 重跑 + `render_views.py` 三视图刷新

```
你在清洗一份中文录音转写稿。源文件：<路径>。输出：<场次目录>/01_清洗稿.md。用中文。

## 说话人映射（主持人已裁决，直接使用）
- <标签> → <人名>（<一句依据>）
- <存疑标签> → 保留原标签，头部注明存疑依据

## 本场 ASR 词表（确定条目直接还原进正文；存疑条目保留原词+标 [ASR/存疑]）
| 原词 | 还原 | …… |

## 分节框架
<短场：固定节界；长场：按话题自然分 8-10 节+话题锚列表>

## 清洗原则（逐回合还原版）
1-5 条标准原则 + 回合格式 `**【人名】** [HH:MM:SS] 正文` + 头部骨架（来源块/映射块/
原则/对照表/附录 A 小节索引+B 金句候选 6-8 条+C 说话人说明+D 忠实性说明）
金句提示（不改原话）：<3-6 条候选话题>

## 输出纪律（防超长终止，必须遵守）
- 中间回复 ≤2 句；每次写入 ≤120 行
- Write 头部+§1+`<!-- APPEND_MARKER_1 -->`，Edit 锚点替换循环到附录写完
- 写完自检：畸形回合=0（grep -cE 在 macOS 中文不可靠，用 python re）、APPEND_MARKER=0
- 最终回复 ≤8 行：状态+回合数+分布+自检结果
```

**附录位置硬要求再强调**：附录 A 必须在文末、标题 `## 附录 A · 小节索引`（放头部会导致校验基底被附录 B 覆盖，引文批量假性失配，见坑库 P41）。子代理按源格式产 [MM:SS] 短时间戳时，主对话统一规范化为 [HH:MM:SS]。
