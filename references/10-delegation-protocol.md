# 单场委派模式（新场次 01 生产外包）

> 适用：**新场次的单场清洗**——01 清洗稿由轻量模型子代理生产，主对话只做不可委派环节。与 `09-batch-cleansing.md`（几十场存量批量）互补：批量模式省人，委派模式省**主对话上下文**。
> 依据：2026-09-07 Task 7 试点两场验证（标准档 30min 场 + 重装档 57min 场，各一次通过）。

## 启用条件

项目根 `pipeline.config.json` 的 `delegation.enabled=true`（本项目默认开）。无 config 的外部项目默认主对话直洗（本模式不启用）。

## 分工表（纪律：映射与提炼不委派）

| 环节 | 执行者 | 说明 |
|---|---|---|
| 说话人映射 | **主对话** | 读原文（短场全读/长场读头尾+抽中段），产出映射结论+存疑词表——最高风险环节，不委派 |
| 01 清洗稿 | **轻量模型子代理** | 自包含 prompt 五要素（见下），分节可由主对话给定框架（短场）或让代理按话题自定（长场 8-10 节） |
| 格式自检+忠实度抽验 | 主对话 | 跑下方质检命令；忠实度=时间戳对齐法抽样 10 回合 |
| 02-09 模块提炼 | **主对话** | 价值核心不委派；基于 01 与映射，无需重读原文 |
| 渲染+场后同步+audit | 主对话 | render_pack → 词表/索引/README/atoms/视图/wiki-sync → 场后审计收口（自备脚本，非本 skill 内置） |

## 委派 prompt 五要素（缺一即漂移）

1. **映射结论**：标签→人名+置信度依据；身份未定者保留原标签+存疑说明
2. **本场词表命中**：确定条目（直接还原）与存疑条目（保留原词+标注）分开列
3. **清洗原则**：合并碎片/去口水/金句原话不改/回合格式 `**【人名】** [HH:MM:SS]`
4. **分节框架**：短场给固定节界，长场给话题锚让代理自定；会后混录段→附录 E 指令
5. **输出纪律**：中间回复 ≤2 句；**每次写入 ≤120 行**；Write 头部+`<!-- APPEND_MARKER_N -->` 分块 Edit；写完 python 自检（畸形回合=0/锚点=0）报回合分布

（完整可复制模板见本文件附录；实战：两场 227/293 回合均一次通过。）

## 主对话质检协议（委派场专用三件）

```bash
# 1 格式权威统计（勿用 grep——macOS UTF-8 字符类坑）
python3 -c "import re,collections; c=collections.Counter(m.group(1) for m in re.finditer(r'\*\*【([^】]+)】\*\* \[', open('<01路径>').read())); print(dict(c))"

# 2 忠实度抽验（时间戳对齐法，期望平均 0.65-0.85=正常清洗区间；<0.5 需逐段人工复核）
#    按 01 回合时间戳取原文同时间戳±1 块拼接做 SequenceMatcher
# 3 引文终校（02/08 引文 vs 01 归一化子串）——轻量模型版 01 骨架非标准结构，verify_quotes 会跳过，故用替代脚本：
#    strip 括注/标注 → norm 标点 → 逐条 `in c1n` 判断（先 strip 再 norm，顺序反了括注会残留假阳性）
```

## 已知坑（P33 起累积）

| # | 坑 | 对策 |
|---|---|---|
| P33 |轻量模型版 01 用自定义骨架，verify_quotes 识别不了 → 引文无校验 | 用「引文终校」替代脚本（见上） |
| P34 | 主对话写 02/08 引文凭记忆会删节失配（12 处教训） | 引文必须从 01 grep 实文复制，禁止凭阅读记忆写 |
| P35 | 口吃重复（「前面/前端」）是原文保真的一部分 | 终校脚本报失配时先查原文是否口吃，勿「顺手修正」 |
| P36 | 委派 prompt 误带不存在金句 |轻量模型应拒录并报告（实战已正确执行一次） |
| P37 | 映射初判可能错（某场次「疑 B/D」实为F） | 抽验 00/01 时对照跨场事实（合同/付款/项目名是硬证据）；错则当场订正+标签批量替换 |
